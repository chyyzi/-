01 / 出发指南

先学会，放轻脚步。

顺着小路自由探索。鸟类会留意你的动静，安静靠近会让观察更从容。

W A S D前后左右移动
鼠标转动视角
Shift按住冲刺
Ctrl按住下蹲潜伏
Space跳跃
R回到入口
H打开 / 合上手册
F进入 / 退出全屏
Esc关闭窗口 / 释放鼠标
观察小贴士

靠近鸟类时按住 Ctrl。潜伏不会增加警觉值；近距离冲刺会惊动它们。看到「!」时，先停下脚步。

02 / 镜头笔记

把相遇，留在照片里。

先找一个合适的位置，再举起相机。变焦能帮助你保持距离。

  1. C
    举起相机

    出现取景框；再次按 C 收起。

  2. 滚轮
    调整画面大小

    向上放大、向下缩小。左下角实时显示 1.0×～4.0×。

  3. 左键 / E
    按下快门

    鸟类进入画面且没有被树石挡住时，可留下观察记录。

  4. P
    翻开相册

    点击照片查看大图，并保存到电脑。取景框不会进入照片。

记录属于你

照片保存在当前浏览器的本地相册，清理浏览器数据会清空。喜欢的照片请及时下载。

03 / 鸟类清单

今天，遇见了谁？

拍到鸟类即可解锁记录。占位球沿用同一套观察与拍照逻辑，之后会替换为正式鸟类模型。

安静等待，也是一种回应

受惊的鸟会离开；这次测试中，等待一会儿会再次出现。手册里的记录会保留。
